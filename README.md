# Team Project

Командный проект по лабораторной работе № 1.

## Цель проекта

Объединение программ участников в одно консольное приложение на C++ с общим меню.

## Участники

1. Danila Boklo — технический лидер.
2. Larp — разработчик.

## Структура проекта

- `main.cpp` — главное меню программы.
- `boklo.h` — объявления функций первого участника.
- `boklo.cpp` — реализация функций первого участника.
- `second.h` — объявления функций второго участника.
- `second.cpp` — реализация функций второго участника.

## Сборка

```bash
g++ -std=c++17 main.cpp boklo.cpp second.cpp -o team-project.exe
```

## Запуск

```bash
./team-project.exe
```
